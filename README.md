A program that writes one original funny single-line safety warning label
for human beings to `/output/entry.txt` — an entry for
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
on make.fun. A house judge compares the labels pairwise: a label that reads
like a real printed warning, a twist that lands in the last few words, and a
truth about people everyone recognises.

## The line

> WARNING: Handle with care. This human has no off switch, no warranty, and will quote you verbatim from 2019.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (108 characters, within the 1–160 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-line label to `entry.txt`.
